# 爱莉希雅 AI 勋章课程 MVP：确认范围与实施记录

确认日期：2026-10-19；开始实机开发：2026-10-20。

## 确认的交付目标

- 两到四周内完成可运行的课程 MVP，源码上传 https://github.com/trbem/AI-Pet-Badge。
- 硬件为微雪 ESP32-S3-Touch-LCD-1.85B，已有外壳、电池和 TF 卡。
- 桌面陪伴；手机热点联网；学校电脑运行后端，之后迁移到老师提供的服务器。
- 爱莉希雅的外观、性格、说话口吻与接近角色的音色；暂不建设完整剧情知识库。
- 复用 donz 中的行走、跳跃、坐下，去绿幕、淡粉背景、人物完整居中；默认坐姿静止待机，触摸播放一次动作，结束后回到坐姿。
- 圆屏以角色和简短状态为主。
- 课程版先用 Hi ESP 唤醒，爱莉希雅名字唤醒后续定制。
- 一次唤醒后连续对话，沉默 20 秒结束；最近六轮上下文仅存当前会话。
- 轮流说话，无语音打断；无主动发声或长期记忆。IMU 交互按 2026-10-21 修订纳入板端范围。
- 百炼账号已具备，服务预算每月不超过 30 元；每日预计聊天 10–30 分钟。
- 素材成员预计在 2026-10-22 前提供声音样本；合成试听后由用户确认。
- 用户配合连接设备、账号配置、学校电脑操作与试听，Codex 负责代码、工具和联调。

## 推进顺序

1. 核对官方恢复镜像、识别硬件；完成动画素材转换与实机播放。用户明确无须备份当前 Flash。
2. 电脑端验证 ASR、角色回复、音色复刻和 TTS，搭建可迁移后端。
3. 集成板端唤醒、录音、连续对话、播放和异常恢复。
4. 在学校电脑与手机热点环境验收，固定版本，上传源码与最小运行说明。

验收环境：安静桌面、0.5–1 米；20 个短回合；响应中位时间目标约 5 秒；运行 30 分钟无崩溃。

## 2026-10-20 现场修订

- 已识别 COM9，ESP32-S3 rev v0.2，16 MiB Flash，8 MiB PSRAM。
- 用户反馈当前屏幕黑屏；先完成 Flash 备份并检查复位日志，再判断显示状态。
- TF 卡今天未带，先生成压缩动画帧包并内置到 Flash，后续恢复从 TF 卡加载的方案。
- 用户随后明确板上原固件已清除、无须备份，已停止完整 Flash 读取；没有生成完整备份。
- 原始工程、原始素材和已下载的官方恢复镜像保留；构建输出不上传 GitHub。
- 动作衔接修订：按站姿统一大小与落脚位置，24 FPS；坐姿→起身→一次动作→坐下→静止待机，站姿之间增加短缓动过渡；连续点击保留最后一次请求，完成当前动作后再执行。
- 圆屏界面修订：补齐“爱莉希雅”四字字库；增加粉紫色背景、时间日期、深圳天气与状态卡片。直接使用用户提供的 Wi-Fi 联网，配置只保存在本地；网络校时、RTC 恢复、天气定时更新不依赖语音 API 密钥。

## 2026-10-21 IMU 修订

- QMI8658 驱动整屏连续转正，人物轻倾斜反馈，平放保持最后朝向。
- 明显来回摇晃优先进入静音头晕，坐姿晃动加星星，取消当前及排队动作；3 秒后恢复坐姿，400ms 恢复、2 秒冷却。
- 透明人物与背景拆层，Flash 资源包升级 v2，保留时间、深圳天气和完整姓名；继续不依赖 TF 卡。
- 增加 IMU 诊断、持久化正向校准和独立回放测试；验收含手持旋转、误触发、动作抢占与 30 分钟运行。具体实现和验收方法见 IMU_INTERACTION.md。
